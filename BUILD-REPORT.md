## ⚠️ Outstanding: Database Connection Required

The Vercel Storage API (Neon provisioning) is not available for this account tier via the API. The database must be connected manually.

### Steps to connect the database

1. **Go to Vercel Dashboard** → Project `comedy-tribune-website` → Storage tab
2. **Create or connect a Neon Postgres database** named `comedy-tribune-db`
3. **Link it to the project** (all environments: production, preview, development)
4. **⚠️ Check env var cross-contamination** (known Neon/Vercel bug):
   - After linking, compare `POSTGRES_HOST` vs `NEONDB_PGHOST` in Vercel env vars
   - If they differ, manually overwrite ALL `POSTGRES_*` / `DATABASE_URL` vars to match the `NEONDB_*` values
5. **Run migrations** using the script in this repo:
   ```bash
   export POSTGRES_URL="postgres://..."  # from Vercel env vars
   bash scripts/migrate.sh
   ```
6. **Redeploy** the project to pick up the new env vars
